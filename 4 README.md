# Email Spam Detection with Machine Learning

## Project Overview
Email Spam Detection is a Machine Learning project that classifies email or message text as **Spam** or **Not Spam (Ham)**.

Spam messages may contain unwanted advertisements, suspicious links, or fraudulent content. This project demonstrates how Machine Learning can identify spam messages by learning patterns from labelled text data.

This project is completed as part of the OASIS INFOBYTE Data Science Internship.

## Objectives
- Understand and explore the spam detection dataset.
- Clean and prepare text data for analysis.
- Convert text into numerical features.
- Train a Machine Learning classification model.
- Classify messages as spam or not spam.
- Evaluate model performance using suitable classification metrics.
- Test the model on sample messages.

## Dataset Description
The project uses a labelled dataset containing text messages or emails and their corresponding categories.

### Important Fields
- **Message or Email Text:** The content to be classified.
- **Label or Category:** Indicates whether the message is spam or not spam.

The exact column names and dataset structure depend on the CSV file used in the notebook.

## How the Project Works
The model learns patterns from labelled messages during training. Text is converted into numerical features so that the classification algorithm can process it.

When a new message is provided, the trained model analyzes its features and predicts whether it belongs to the spam or not-spam category.

## Model Evaluation
The model's performance can be assessed using the following metrics:

- **Accuracy:** Measures the proportion of correct predictions.
- **Precision:** Measures how many messages predicted as spam are actually spam.
- **Recall:** Measures how many actual spam messages are correctly identified.
- **F1-Score:** Balances precision and recall.
- **Confusion Matrix:** Shows correct and incorrect predictions for each class.

These metrics help evaluate the model's ability to identify spam messages while limiting incorrect classifications.
